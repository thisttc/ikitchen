# Photo fixtures

Four JPEG crops from an existing photograph, used only to test bitmap loading and face placement.
No generated artwork or manually drawn product details are included.

Source: https://images.unsplash.com/photo-1571175443880-49e1d25b2bc5?w=700
License information: https://unsplash.com/license

The crops are deliberately rough and are not calibrated front/right photographs.
The `front` and `right` names describe the test face receiving each file.
Sample dimensions in products.json do not describe the photographed furniture.
